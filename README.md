# চালক — ড্রাইভার সার্ভিস ও জব প্ল্যাটফর্ম

বাংলাদেশে ড্রাইভার খোঁজা এবং ড্রাইভারের চাকরির জন্য ওয়েবসাইট, অ্যাডমিন প্যানেল ও API। প্রথম পর্যায়ে ঢাকা ও চট্টগ্রাম চালু। বাকি ৬৪ জেলার তথ্য ডেটাবেসে আছে; অ্যাডমিন প্যানেল থেকে জেলা চালু করলেই সার্চে আসে।

## ফোল্ডার

| ফোল্ডার | কী |
| --- | --- |
| `web` | Next.js ওয়েবসাইট — হোম, সার্চ, প্রোফাইল, আবেদন, বিজ্ঞাপন |
| `admin` | Next.js অ্যাডমিন প্যানেল |
| `backend` | NestJS, Prisma, PostgreSQL, Swagger |
| `app` | React Native CLI-র জন্য রাখা ফোল্ডার। এই পর্যায়ে অ্যাপ বানানো হয়নি |

## চালু করা

Postgres এই মেশিনে `5438` পোর্টে চলে, কারণ `5432` অন্য প্রজেক্টে ব্যবহৃত।

```bash
docker compose up -d
npm install --prefix backend && npm install --prefix web && npm install --prefix admin
npm run prisma:generate --prefix backend
npm run db:push --prefix backend
npm run seed --prefix backend
```

তিনটি টার্মিনাল:

```bash
npm run start:dev --prefix backend
npm run dev --prefix web
npm run dev --prefix admin
```

- ওয়েবসাইট: http://localhost:3010
- অ্যাডমিন: http://localhost:3001
- API ডকুমেন্ট: http://localhost:4000/docs

## ডেমো লগইন

| ভূমিকা | মোবাইল | পাসওয়ার্ড |
| --- | --- | --- |
| সুপার অ্যাডমিন | 01700000000 | Admin@12345 |
| কনটেন্ট | 01700000002 | Staff@12345 |
| সাপোর্ট | 01700000003 | Staff@12345 |
| ড্রাইভার | 01711111111 | Driver@12345 |
| নিয়োগকর্তা | 01722222221 | Employer@12345 |

আরও ড্রাইভার `01711111112` থেকে `01711111118`। আরও নিয়োগকর্তা `01722222222` থেকে `01722222224`। সবার ড্রাইভার পাসওয়ার্ড `Driver@12345`, নিয়োগকর্তার `Employer@12345`।

লোকাল OTP `OTP_DEV=true` থাকলে রেসপন্সে `devOtp` আসে। প্রোডাকশনে এটি বন্ধ রাখুন।

## এই সংস্করণে যা আছে

- বাংলা ও ইংরেজি, মোবাইল লেআউট, SEO URL, সাইটম্যাপ
- ড্রাইভার প্রোফাইল, গাড়ি, অভিজ্ঞতা, রেফারেন্স, লাইসেন্স ফাইল
- ড্রাইভার সার্চ ও চাকরির সার্চ
- বিজ্ঞাপন খসড়া, অ্যাডমিন অনুমোদন, মেয়াদ শেষে বন্ধ
- আবেদনের ধাপ: জমা, পর্যালোচনা, সাক্ষাৎকার, নিয়োগ, বাতিল
- সার্চ থেকে ফোন শুধু ড্রাইভার রাজি হলে
- চাকরিতে আবেদন করলে সেই নিয়োগকর্তা ফোন দেখেন
- অভিযোগ, কনটেন্ট, বার্তা, অডিট লগ, স্টাফের আলাদা অনুমতি
- বিভাগ, ৬৪ জেলা, ঢাকা ও চট্টগ্রামের থানা/উপজেলা
- প্ল্যানের টেবিল রাখা আছে, টাকা কাটা হয় না

## পরে, আলাদা খরচ

- এসএমএস গেটওয়ে
- ইমেইল এসএমটিপি (`SMTP_*` খালি থাকলে ইমেইল শুধু লগ হয়)
- bKash, Nagad বা SSLCommerz
- WhatsApp
- React Native অ্যাপ

Google Analytics চালু করতে `web` এ `NEXT_PUBLIC_GA_ID` দিন। Search Console-এর জন্য `NEXT_PUBLIC_GSC_VERIFICATION`।

প্রকাশের আগে `.env` এর JWT সিক্রেট বদলান এবং ডেমো পাসওয়ার্ড সরিয়ে দিন। গোপনীয়তা নীতি একজন আইনজীবীকে দেখিয়ে নেওয়া উচিত।
